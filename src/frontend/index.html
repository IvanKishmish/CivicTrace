Комунальне майно Полтави

Комунальне майно має бути видимим і зрозумілим

Мета CivicTrace — допомогти бізнесу знаходити приміщення для оренди, а громаді — бачити, як комунальне майно передається в оренду та що відбувається на аукціонах.

Міські дані та Prozorro.Продажі зведені так, щоб потрібний об’єкт і його історію було легше знайти та перевірити.

Огляд оренди й сигнали для перевірки Відкрити карту

Звідки беруться дані й що робить CivicTrace

  1. Міський перелікДає початкові ID об’єктів оренди та короткі назви.
  2. Звірка з API Prozorro.ПродажіЗіставляємо ID зі знайденими записами, додаємо відомості про об’єкти та пов’язані аукціони. Не для кожного ID джерело повертає всі поля.
  3. Каталог, карта й аналітикаЗводимо знайдене за об’єктом, додаємо фільтри та позначаємо сигнали, які варто перевірити.

У картках видно, звідки взялися відомості. Якщо у джерелі бракує даних або координат, ми окремо показуємо, чого саме не вдалося знайти.
