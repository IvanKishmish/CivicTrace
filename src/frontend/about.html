Як працює збагачення 553 об’єктів та оцінка ризиків

Рішення побудовано виключно на відкритих даних без скрапінгу та без зберігання персональних даних фізичних осіб.

Виявлені дефекти вихідного набору P3-01

  • Лише 3 колонки: у всіх 553 рядках відсутні адреса, площа, статус і балансоутримувач — доповнюються з API Prozorro.Продажі.
  • 4 биті URL: подвійний слеш planning// у рядках 7, 11, 58, 259.
  • Сторонній майданчик: рядок 191 (RGL001-UA-20210920-01299) веде на sale.uub.com.ua.
  • Описка та пробіли: «нежитові приміщення» у RGL001-UA-20210916-80842 та зайві пробіли у рядках 300, 314–341.

Етика, доступ і ліцензії

  • Ризики, а не особи: ФОП і фізичні особи повністю знеособлені.
  • Розділення доступу: публічна частина відкрита всім; синхронізація API доступна лише адміністратору.
  • Ліцензії: код — MIT, методика індикаторів — CC BY 4.0 (детально в METHODOLOGY.md).
