Навіщо CivicTrace

Від списку ID — до зрозумілої картини оренди

Міський перелік містить ID та коротку назву. Щоб зрозуміти, де об’єкт, якої він площі, хто його утримує та чи є пов’язані аукціони, доводиться шукати й відкривати записи окремо. CivicTrace збирає ці відомості в одній картці, каталозі та на карті.

Як це працює на практиці

  1. Міський файл задає перелік об’єктів та їхні ID формату RGL….
  2. Синхронізація звертається до відкритого API Prozorro.Продажі й звіряє ID з опублікованими записами. Пов’язані процедури аукціонів додаються до картки об’єкта.
  3. CivicTrace показує зіставлені дані разом: адреса, площа, статус, балансоутримувач, аукціони та, де можливо, координати.
  4. Користувач шукає й фільтрує записи, переглядає карту чи аналітику та переходить за посиланням до першоджерела.

Що CivicTrace додає до Prozorro.Продажі

Prozorro.Продажі публікує офіційні записи та проводить торги. CivicTrace не дублює торги й не приймає заявок: він поєднує міський перелік з API, дає пошук по всьому набору, карту, огляд кількох аукціонів біля одного об’єкта, перевірку якості даних і експорт таблиці.

Оновлення

Сервер періодично синхронізує дані з API; адміністратор також може запустити оновлення вручну. Коли джерело не повертає запис або поле, CivicTrace показує його як відсутнє, а не вигадує значення.

Кому це корисно

  • Підприємцю: знайти запис за площею чи районом і перейти до офіційної сторінки, щоб перевірити умови та актуальність пропозиції.
  • Міському працівнику: побачити зведений перелік, пропуски в даних і пов’язані аукціони без ручного відкриття кожного ID.
  • Журналісту або мешканцю: переглянути об’єкт, його історію та сигнали, які варто перевірити в першоджерелі.
Межі даних. Каталог починається з наданого міського файлу й не є повним реєстром майна громади. «Вільне» означає лише статус, який вдалося визначити для запису в цьому наборі. Перед дією перевірте актуальні умови на Prozorro.Продажі.

Як розуміти сигнали

Сигнал — це правило для сортування випадків на перевірку, наприклад один учасник аукціону чи повторні невдалі спроби. Бал не є ймовірністю порушення, а сигнал не є висновком про порушення. У картці показано причину та можливе легітимне пояснення.

Чому деякі поля відсутні

API може не містити адресу, площу, координати або пов’язану процедуру, або зіставлення ще не вдалося. Відсутність поля не означає, що об’єкта немає. На карті показуються лише записи з координатами, але всі доступні записи залишаються в каталозі.
