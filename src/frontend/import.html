Адміністрування CivicTrace

Публічний каталог і аналітика відкриті гостям. Ця сторінка потрібна лише адміністратору для оновлення даних із Prozorro.Продажі.

Вхід адміністратора

Форма публічної реєстрації поки не потрібна: акаунти відвідувачів не мають окремих функцій, а самореєстрація не надає прав адміністратора.

Оновити дані з Prozorro.Продажі

Міський файл задає список ID об’єктів. Синхронізація шукає відповідні записи у відкритому API, оновлює дані об’єктів і додає пов’язані аукціони. Потім CivicTrace оновлює карту та сигнали для перевірки.

Сервер також запускає синхронізацію автоматично приблизно кожні 30 хвилин. Ручне оновлення працює у фоні: можна перейти на іншу сторінку й повернутися сюди, щоб побачити стан. Якщо API не повернуло дані для ID, запис залишиться в каталозі з позначкою про неповні відомості.
