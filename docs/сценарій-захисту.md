# Сценарій демонстрації CivicTrace

## Головна думка

**CivicTrace допомагає бізнесу знайти комунальне приміщення, а громаді — зрозуміти, що відбувається з майном під час оренди та аукціонів.** Замість ручного пошуку в багатьох записах сервіс збирає міський список та відкриті дані Prozorro.Продажі в каталозі, на карті й у зведеній аналітиці.

## Демонстрація на 3–4 хвилини

### 1. Головна сторінка — мета, 20 секунд

**Показати:** заголовок і три кроки «міський перелік → API Prozorro.Продажі → каталог, карта й аналітика».

**Сказати:**

> «Проблема не в тому, що даних зовсім немає. Вони розкидані: у міському списку є ID, а подробиці про об’єкт і його аукціони треба шукати окремо. CivicTrace зводить їх, щоб приміщення було простіше знайти, а історію оренди — перевірити».

### 2. Каталог — знайти конкретний запис, 45 секунд

**Натиснути:** поле пошуку, ввести `Низова`, натиснути на картку знайденого об’єкта.

**Показати:** адресу, площу, статус, балансоутримувача, ID об’єкта, аукціони та посилання на Prozorro.Продажі.

**Сказати:**

> «Наприклад, замість переглядати весь список, я шукаю за частиною адреси. В одній картці бачу дані, які вдалося зіставити, і можу перейти до першоджерела, щоб перевірити актуальні умови».

Не обіцяти, що будь-який запис є вільним або що кожне поле заповнене: показати фактичний статус вибраної картки.

### 3. Пояснити числа й синхронізацію, 30 секунд

**Показати:** картки з кількістю записів і «Знайдено дані Prozorro.Продажі».

**Сказати:**

> «Число записів у міському списку — це розмір початкового файлу. Синхронізація не додає нові міські об’єкти: вона звіряє їхні ID з API та оновлює відомості й аукціони. Тому число міського списку може лишатися тим самим, а змінюються час оновлення та кількість записів, для яких вдалося знайти дані в API».

Якщо запитають про доступність приміщень: назвати показаний зараз лічильник вільних і невизначених статусів. Не робити висновок про все майно Полтави — сервіс працює з наданим міським списком.

### 4. Карта — статуси та сигнали, 45 секунд

**Натиснути:** «Відкрити карту». Спочатку залишити «Усі статуси», показати легенду. Потім за бажанням увімкнути сигнал ризику або вибрати статус.

**Сказати:**

> «Кольорові кружки — це записи об’єктів, а не всі зелені плями на підкладці. Темно-зелена точка означає, що статус у даних визначений як вільний; світло-зелені ділянки — парки на карті. Якщо за фільтром вільних точок немає, це означає, що в поточному наборі немає геокодованих записів із таким статусом».

> «Червоне кільце навколо точки показує сигнал для перевірки. Воно не означає доведене порушення. Для кожної точки без координат є окремий підрахунок, а сам запис можна знайти в каталозі».

Якщо вільних об’єктів зараз нуль, не намагатися показати неіснуючу точку. Показати повідомлення порожнього результату й пояснити, що воно стосується саме цього списку та його поточних даних.

### 5. Аналітика — навіщо це громаді, 45 секунд

**Натиснути:** «Огляд оренди й сигнали для перевірки».

**Показати:** розподіл за статусами, роками, типами; таблицю сигналів і таблицю записів, що потребують перевірки.

**Сказати:**

> «Тут не виноситься юридичний вердикт. Аналітика швидко показує, де бракує даних і які випадки варто відкрити детальніше. Наприклад, один учасник або повторні невдалі аукціони — причина поставити додаткове запитання, а не доказ порушення».

Не називати оцінку потенційного доходу фактичними надходженнями: це орієнтовний розрахунок на площі та медіанній ставці.

### 6. Завершення — відмінність від Prozorro.Продажі, 20 секунд

**Сказати:**

> «Prozorro.Продажі — першоджерело записів і система, де відбуваються торги. CivicTrace не замінює її й не приймає заявок. Він допомагає швидше знайти дані по міському переліку, побачити об’єкт на карті, звести історію аукціонів і визначити, що варто перевірити».

## Показ адмін-синхронізації

Якщо журі просить показати оновлення, відкрити «Вхід адміністратора» й пояснити ланцюжок: міський список ID → API Prozorro.Продажі → зіставлені записи та аукціони → оновлені картки, карта й аналітика. Синхронізація виконується у фоні; показувати стан завдання та підсумкові числа лише після того, як сервер їх повернув. Не називати процес успішним, якщо підсумкові числа не відображені.

## Короткі відповіді журі

- **Чому список має 553 записи?** Це число ID у наданому міському файлі. Воно не є кількістю вільних приміщень і не змінюється під час синхронізації.
- **Що робить API?** Дає опубліковані дані об’єктів і процедур; CivicTrace зіставляє записи за ID та додає знайдені аукціони.
- **Чому дані можуть бути неповними?** Для частини ID API не повертає потрібний запис або окремі поля. Ми показуємо такі прогалини, а не підміняємо їх припущеннями.
- **Чим сервіс корисніший за пошук у Prozorro?** Дає єдиний пошук по міському списку, карту, зведення пов’язаних аукціонів, контроль прогалин і пояснювані сигнали для перевірки.
- **Чи означає сигнал порушення?** Ні. Він позначає запис, який може потребувати контексту й ручної перевірки.
